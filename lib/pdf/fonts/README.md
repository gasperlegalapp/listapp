Latin subsets of the app's three typefaces, embedded in PDFs so they match
the screen. Headless Chromium on Vercel has no fonts of its own.

- archivo-latin.woff2 (Archivo, variable weight)
- source-serif-4-latin.woff2, source-serif-4-italic-latin.woff2 (Source Serif 4, variable)
- ibm-plex-mono-400-latin.woff2, ibm-plex-mono-500-latin.woff2 (IBM Plex Mono)

All three are from Google Fonts under the SIL Open Font License 1.1
(https://openfontlicense.org), the same files next/font serves to the app.
